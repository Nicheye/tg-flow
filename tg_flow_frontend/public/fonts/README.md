# UI fonts

DM Sans (main, variable normal) and Redaction 50 (accent, regular), sourced from Google Fonts and served locally as WOFF2. Latin and Latin Extended subsets are included. Other scripts use the system fallback. Both families use the SIL Open Font License; license files are included alongside the fonts.

Sources: https://fonts.google.com/specimen/DM+Sans and https://fonts.google.com/specimen/Redaction+50.
